# Анализ успеваемости

Лабораторная работа №2 по проектированию веб-сайтов. Масленникова Ия, ОВБИ-303Б.

Запуск из папки репозитория

```sh
node main.js
```

Программа выводит средний балл, имя лучшего студента, имена студентов с баллом ниже 60 и итоговый массив с буквенными оценками. Баллы от 90 дают A, от 75 до 89 дают B, остальные дают C.
